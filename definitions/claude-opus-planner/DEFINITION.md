# Claude Code + Opus for planning and review

The team's recommended agent for the thinking-heavy tasks: specs and designs (**Planning**), and judging other
agents' work and accepting stories (**Review**). Opus at high effort is slower and uses more tokens than Sonnet,
which is why it isn't used for Building.

`opus` is Claude Code's alias for the current Opus model, so this definition keeps working when a new Opus
version comes out. «Start an agent» from it pre-ticks the categories Planning and Review.
